# Test images

## characters/ — real children's drawings

From Meta's [AnimatedDrawings](https://github.com/facebookresearch/AnimatedDrawings) repository
(`examples/characters/char1..6`, `examples/drawings/garlic.png`), MIT licensed — see
`characters/LICENSE-Meta-AnimatedDrawings.txt`.

| folder | Meta source | what it is |
|---|---|---|
| `boy_crown` | char1 | boy with a crown (marker) |
| `girl_ballerina` | char2 | ballerina (pencil) |
| `candy_corn_monster` | char3 | candy-corn monster with arms and legs (crayon) |
| `stick_figure` | char4 | stick figure (+ `page.png`: the full photo, drawing lies sideways among other doodles) |
| `bug_monster` | char5 | six-armed bug; Meta's annotation uses a custom 28-joint skeleton |
| `pig_animal` | char6 | four-legged pig |
| `garlic_monster` | drawings/garlic.png | photo of a garlic monster, no annotations |

Per folder: `crop.png` (Meta's `texture.png`: the cropped photo), `meta_mask.png` and
`meta_char_cfg.yaml` (Meta's segmentation and pose-model skeleton, used as ground truth),
`page.png` (the full photo, downscaled to <= 1000 px, when Meta ships one) and
`meta_bounding_box.yaml` (Meta's detector box).

## backgrounds/

* `real_kid_room_photo.png` — a real child's drawing of a room (Meta's `char4/background.png`,
  MIT), photographed with a thumb and fabric in frame.
* The other scenes are generated by `generate_crayon_scenes.py` to look like children's crayon
  drawings (wobbly outlines, strokes that leave paper showing, lollipop trees, triangle-roof
  houses) and come with `*.truth.json` listing every object for scoring the analyzer.
  Real kid-drawn landscapes with redistributable licences couldn't be downloaded from the
  build sandbox (only GitHub was reachable), so these stand in for them.
